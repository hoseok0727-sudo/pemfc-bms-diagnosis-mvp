# PEMFC BMS 상태진단 MVP 쉬운 계산 설명 보고서

## 1. 아주 쉽게 말하면

이 시스템은 “현재 전류와 온도라면 정상 연료전지는 이 정도 전압이 나와야 한다”는 기준선을 만들고, 실제 전압이 그 기준보다 얼마나 낮아졌는지 보고 상태를 판단한다.

사용 데이터는 네 가지이다.

| 데이터 | 의미 |
| --- | --- |
| 전압 | 연료전지가 실제로 내는 전압 |
| 전류 | 부하가 얼마나 걸렸는지 |
| 온도 | 스택 또는 냉각수 조건 |
| 운전시간 | 시간이 지나며 전압이 떨어지는지 보는 기준 |

## 2. 계산 흐름

1. 전압, 전류, 온도, 운전시간 데이터를 읽는다.
2. 이동평균으로 센서 노이즈를 줄인다.
3. 초기 정상 구간으로 정상 전압 기준선을 만든다.
4. 실제 전압과 기준선의 차이, SOH proxy, 열화율을 계산한다.
5. Normal, Warning, Check, Critical 중 하나로 표시한다.

## 3. 출력 Power

현재 스택이 만들어내는 전력이다.

```latex
P(t)=V_{\mathrm{stack}}(t)\times I(t)
```

출력이 낮다고 무조건 고장은 아니다. 부하 전류가 작으면 출력도 작다.

## 4. 정상 전압 기준선

현재 전류와 온도 조건이라면 정상 스택 전압이 어느 정도여야 하는지 예측한다.

```latex
\hat{V}_{\mathrm{normal}}(t)=
\beta_0+\beta_1 I(t)+\beta_2 I(t)^2+\beta_3 T(t)+\beta_4 I(t)T(t)
```

이 식은 물리식이 아니라 BMS 데이터 기반 경험식이다.

## 5. 전압 잔차

실제 전압에서 정상 기준 전압을 뺀 값이다.

```latex
r_V(t)=V_{\mathrm{stack}}(t)-\hat{V}_{\mathrm{normal}}(t)
```

0 근처면 정상 기준과 비슷하다. 음수로 커질수록 정상보다 전압이 낮다는 의미다.

## 6. 잔차 z-score

전압 잔차가 정상 구간에서 보이던 흔한 변동인지, 보기 드문 큰 하락인지 나타낸다.

```latex
z_V(t)=\frac{r_V(t)-\mu_r}{\sigma_r}
```

`z = -2` 정도면 Warning, `z = -3` 정도면 Check, `z = -4` 이하면 Critical 신호로 볼 수 있다.

## 7. 운전조건 보정 전압

전류와 온도 조건 차이 때문에 생긴 전압 변화를 제거한 값이다.

```latex
V_{\mathrm{corr}}(t)=V_{\mathrm{stack}}(t)-
\left[
\hat{V}_{\mathrm{normal}}(I(t),T(t))-
\hat{V}_{\mathrm{normal}}(I_{\mathrm{ref}},T_{\mathrm{ref}})
\right]
```

서로 다른 운전 조건의 전압을 같은 기준 조건처럼 비교하기 위해 사용한다.

## 8. SOH proxy

초기 정상 상태의 보정 전압을 100%로 놓고, 현재 보정 전압이 몇 % 수준인지 계산한다.

```latex
SOH_{\mathrm{proxy}}(t)=
\frac{V_{\mathrm{corr}}(t)}{V_{\mathrm{corr}}(t_0)}\times100
```

이 값은 실제 완전한 SOH가 아니라 전압 기반 SOH proxy이다.

## 9. 열화율

최근 구간에서 보정 전압이 시간에 따라 얼마나 빨리 떨어지는지 보는 값이다.

```latex
V_{\mathrm{corr}}(t)\approx a+k_{\mathrm{deg}}t
```

```latex
k_{\mathrm{deg}}=\frac{dV_{\mathrm{corr}}}{dt}
```

`k_deg < 0`이면 전압이 감소하는 추세다.

## 10. 간이 RUL

현재 전압 하락 속도가 그대로 유지된다고 가정했을 때, EOL 기준 전압까지 남은 시간을 계산한다.

```latex
RUL=\frac{V_{\mathrm{EOL}}-V_{\mathrm{corr}}(t)}{k_{\mathrm{deg}}}
\qquad (k_{\mathrm{deg}}<0)
```

RUL은 실제 고장 시점을 정확히 예측하는 값이 아니라, 현재 전압 저하 추세가 유지된다는 가정하의 간이 잔여 운전시간 지표이다.

## 11. 상태 판정

| 상태 | 기준 예시 | 의미 |
| --- | --- | --- |
| Normal | `SOH > 95%`, `z > -2` | 정상 기준과 비슷함 |
| Warning | `90% < SOH <= 95%` 또는 `z <= -2` | 전압 저하 신호 시작 |
| Check | `80% < SOH <= 90%` 또는 `z <= -3` | 점검 권고 |
| Critical | `SOH <= 80%` 또는 `z <= -4` | 정밀 점검 또는 운전 제한 필요 |

## 12. 한계

이 시스템은 EIS, HFR, Rct, 셀별 전압을 사용하지 않는다. 따라서 촉매 열화, 막 건조, flooding, 수소 부족 같은 구체적인 고장 원인을 확정하지 않는다.

정확한 표현은 “BMS 데이터 기반 조기 이상감지 및 유지보수 보조 시스템”이다.
