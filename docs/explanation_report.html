PEMFC BMS 상태진단 MVP 쉬운 계산 설명 보고서

대시보드에 나오는 숫자가 무엇이고, 왜 그런 판정이 나오는지 쉽게 설명한 버전

1. 아주 쉽게 말하면

이 시스템은 “현재 전류와 온도라면 정상 연료전지는 이 정도 전압이 나와야 한다”는 기준선을 만들고, 실제 전압이 그 기준보다 얼마나 낮아졌는지 보고 상태를 판단한다.
전압 연료전지의 힘이 실제로 얼마나 나오는지 보는 핵심 신호다.
전류 부하가 얼마나 걸렸는지 나타낸다. 전류가 커지면 전압은 원래 낮아질 수 있다.
온도 스택 조건을 나타낸다. 온도도 전압에 영향을 준다.
운전시간 시간이 지나며 전압이 계속 떨어지는지 보는 기준이다.

2. 계산 흐름

대시보드에 보이는 값들은 한 번에 튀어나오는 것이 아니라 아래 순서대로 계산된다. 핵심은 전류와 온도 때문에 자연스럽게 바뀐 전압을 빼고, 성능 저하로 보이는 전압 하락만 따로 보는 것이다.

Step 1전압, 전류, 온도, 운전시간 데이터를 읽는다.
Step 2이동평균으로 센서 노이즈를 줄인다.
Step 3초기 정상 구간으로 정상 전압 기준선을 만든다.
Step 4실제 전압과 기준선의 차이, SOH proxy, 열화율을 계산한다.
Step 5Normal, Warning, Check, Critical 중 하나로 표시한다.

3. 대시보드 숫자별 쉬운 설명

Power, 출력

전기를 얼마나 내는가

의미

현재 스택이 만들어내는 전력이다. 전압과 전류를 곱해서 계산한다.

\[ P(t)=V_{\mathrm{stack}}(t)\times I(t) \]
읽는 법: 출력이 낮다고 무조건 고장은 아니다. 부하 전류가 작으면 출력도 작다. 그래서 출력은 참고 지표이고, 상태진단의 핵심은 전압 잔차와 SOH proxy다.

Normal Baseline, 정상 전압 기준선

비교 기준

의미

“지금 전류와 온도 조건이라면 정상 스택 전압은 얼마쯤이어야 하는가?”를 예측한 값이다. 이 기준선이 있어야 실제 전압이 낮은지 높은지 말할 수 있다.

\[ \hat{V}_{\mathrm{normal}}(t)= \beta_0+\beta_1 I(t)+\beta_2 I(t)^2+\beta_3 T(t)+\beta_4 I(t)T(t) \]
읽는 법: 실제 전압이 기준선 근처에 있으면 정상에 가깝다. 실제 전압이 기준선보다 계속 낮으면 같은 조건에서도 성능이 떨어졌다고 볼 수 있다. 단, 이 식은 물리식이 아니라 BMS 데이터 기반 경험식이다.

Voltage Residual, 전압 잔차

실제값 - 정상값

의미

실제 전압에서 정상 기준 전압을 뺀 값이다. 쉽게 말해 “예상보다 전압이 얼마나 부족한가?”를 보는 값이다.

\[ r_V(t)=V_{\mathrm{stack}}(t)-\hat{V}_{\mathrm{normal}}(t) \]
읽는 법: 0 근처면 정상 기준과 비슷하다. 음수로 커질수록 정상보다 전압이 낮다는 의미다.

Residual Z-score, 잔차 표준점수

얼마나 이상한가

의미

전압 잔차가 정상 구간에서 보이던 흔한 변동인지, 아니면 보기 드문 큰 하락인지 숫자로 바꾼 값이다.

\[ z_V(t)=\frac{r_V(t)-\mu_r}{\sigma_r} \]
읽는 법: \(z_V=-2\) 정도면 주의, \(z_V=-3\) 정도면 점검, \(z_V=-4\) 이하면 심각한 이상 신호로 본다. 값이 음수라는 것은 정상 기준보다 전압이 낮다는 뜻이다.

Corrected Voltage, 운전조건 보정 전압

조건을 맞춰 비교

의미

전류와 온도 조건 차이 때문에 생긴 전압 변화를 제거한 값이다. 즉, 서로 다른 운전 조건의 전압을 같은 기준 조건처럼 비교하려는 값이다.

\[ V_{\mathrm{corr}}(t)=V_{\mathrm{stack}}(t)- \left[ \hat{V}_{\mathrm{normal}}(I(t),T(t))- \hat{V}_{\mathrm{normal}}(I_{\mathrm{ref}},T_{\mathrm{ref}}) \right] \]
읽는 법: 전류와 온도가 달라서 전압이 바뀐 부분을 빼고도 보정 전압이 계속 낮아지면 실제 성능 저하 가능성이 커진다.

SOH Proxy, 전압 기반 건강도

초기 대비 몇 퍼센트인가

의미

초기 정상 상태의 보정 전압을 100%로 놓고, 현재 보정 전압이 몇 % 수준인지 계산한 값이다.

\[ SOH_{\mathrm{proxy}}(t)= \frac{V_{\mathrm{corr}}(t)}{V_{\mathrm{corr}}(t_0)}\times100 \]
읽는 법: 95% 이상이면 정상에 가깝고, 90% 아래면 점검 신호가 강해진다. 단, 이것은 실제 전체 SOH가 아니라 전압 기반 proxy다.

Degradation Rate, 열화율

시간당 전압 감소

의미

최근 구간에서 보정 전압이 시간에 따라 얼마나 빨리 떨어지는지 보는 값이다. 음수이면 전압이 감소하는 추세다.

\[ V_{\mathrm{corr}}(t)\approx a+k_{\mathrm{deg}}t \qquad k_{\mathrm{deg}}=\frac{dV_{\mathrm{corr}}}{dt} \]
읽는 법: 예를 들어 \(-0.004\,V/h\)라면 현재 추세에서 시간당 약 0.004 V씩 보정 전압이 떨어진다는 뜻이다.

Estimated RUL, 간이 잔여 운전시간

추세 기반 남은 시간

의미

현재 전압 하락 속도가 그대로 유지된다고 가정했을 때, EOL 기준 전압까지 남은 시간을 계산한 값이다.

\[ RUL=\frac{V_{\mathrm{EOL}}-V_{\mathrm{corr}}(t)}{k_{\mathrm{deg}}} \qquad (k_{\mathrm{deg}}<0) \]
읽는 법: RUL은 실제 고장 시점을 맞히는 예언값이 아니다. 현재 열화 추세가 계속된다는 가정하에 계산한 유지보수 참고 지표다.

4. 상태 판정은 이렇게 이해하면 된다

상태 판정은 SOH proxy와 z-score를 함께 본다. SOH proxy는 장기적인 성능 저하를 보고, z-score는 지금 전압이 정상 기준에서 얼마나 벗어났는지 본다.

상태 기준 예시 쉬운 의미 대응
Normal \(SOH_{\mathrm{proxy}}>95\%\), \(z_V>-2\) 정상 기준과 비슷하다. 일반 모니터링 유지
Warning \(90\% 전압 저하 신호가 보이기 시작한다. 추세를 더 자주 확인
Check \(80\% 정상 기준에서 의미 있게 벗어났다. 냉각, 온도 제어, 수소/공기 공급 상태 점검
Critical \(SOH_{\mathrm{proxy}}\le80\%\), \(z_V\le-4\), 또는 급격한 전압 저하 운전 제한 또는 정밀 점검이 필요할 수 있다. 정밀 진단 및 운전 조건 재검토

5. UI 그래프를 보는 순서

순서 그래프 확인할 것
1 Voltage and Normal Baseline 실제 전압이 정상 기준선보다 계속 낮아지는지 본다.
2 Residual Z-score \(-2\), \(-3\), \(-4\) 아래로 내려가는지 본다.
3 SOH Proxy 초기 대비 전압 성능이 95%, 90%, 80% 기준에 가까워지는지 본다.
4 Current and Temperature 전류와 온도 조건은 비슷한데 전압만 낮아지는지 확인한다.

6. 가장 중요한 한계

이 시스템은 EIS, HFR, Rct, 셀별 전압을 사용하지 않는다. 따라서 촉매 열화, 막 건조, flooding, 수소 부족 같은 구체적인 고장 원인을 확정하지 않는다.

정확한 표현은 “BMS 데이터 기반 조기 이상감지 및 유지보수 보조 시스템”이다. 이 한계를 분명히 말하면 프로젝트 범위가 과하게 넓어 보이지 않는다.

7. 발표용 짧은 설명

본 MVP는 PEMFC 스택의 전압, 전류, 온도, 운전시간만 사용한다. 초기 정상 구간으로 정상 전압 기준선을 만들고, 실제 전압과 기준선의 차이를 계산한다. 이후 전류와 온도 영향을 보정한 전압으로 SOH proxy와 열화율을 계산하고, 현재 전압 저하 추세가 유지된다는 가정하에 간이 RUL을 추정한다. 최종적으로 상태를 Normal, Warning, Check, Critical로 분류하여 점검 필요성을 알려준다.
